ElementHousing Instructions

## Scope
These instructions apply to this World of Warcraft addon.

## Standards
- All code must use best modern practices.
- Develop for the latest World of Warcraft: Midnight, at -least- Patch 12.1.0.
- Keep all code clean, orderly, organized, secure.
- Keep implementations minimal, practical, and maintainable. Apply Occam's Razor, avoid overengineering, and do not reinvent the wheel.
- Build with security in mind, accounting for common and edge-case vulnerabilities.
- Do not try to circumvent any official Blizzard API practices under any circumstances. 
- Comment all functions and methods in code.
- Follow Blizzard's API development instructions precisely as per their latest articles available as of September 2026
- Do not use any emoji.
- We perform all code work on a local environment
- Check Git diff for previous work when needed.  Git may not currently be initialized, but we can account for this later. 
- Our addon MUST be ElvUI compatible.
